# Demonstration skill

1. Read from this article: https://resources.anthropic.com/hubfs/The-Complete-Guide-to-Building-Skill-for-Claude.pdf

2. Explain to the user what a skill is and how to build it in 5 bullet points.

3. Ask the user if they understood

4. If the user says no, explain it again more intuitively.
