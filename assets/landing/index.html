Progressive disclosure

    
Claude loads a Skill in three steps, and only as far as the task needs.

    
At startup Claude sees each Skill's name and description and nothing else. It opens SKILL.md when a request matches, and it opens reference files or runs scripts only when the instructions point there. Pick a request and step through it.

Level 2 · on matchSKILL.md bodyRead only when the request fits the description.

      
Level 3 · on demandReferences and scriptsFiles Claude opens as needed. Scripts run and only their output enters context.
